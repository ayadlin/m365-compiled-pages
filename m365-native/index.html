Installation:

# For .deb package:
sudo dpkg -i m365-native_*.deb
sudo apt -f install  # Install dependencies

# For AppImage:
chmod +x m365-native-*.AppImage
./m365-native-*.AppImage

🎯 Quick Start

After installation:

  1. Launch "M365 WebApps Native" from your application menu
  2. Enter your license key when prompted
  3. Sign in with Microsoft OAuth 2.0 (one-time setup)
  4. Select any Office app to launch - Word, Excel, PowerPoint, etc.
  5. Stay signed in across all apps!

💡 Native vs Foundation
