🚀 After Installation

1. Verify Installation

m365-native --version m365-pro --version m365ctl --help

2. Activate License

Download your license.json and license.sig from the Customer Portal

mkdir -p ~/.config/m365_webapps cp license.json ~/.config/m365_webapps/ cp license.sig ~/.config/m365_webapps/ # Verify m365-pro -feature picker \ -license ~/.config/m365_webapps/license.json \ -sig ~/.config/m365_webapps/license.sig

3. Launch Native App

Launch the native OAuth-enabled Microsoft 365 interface:

m365-native # OR click the desktop launcher

OAuth Benefits:

  • 🔑 Single sign-on - authenticate once
  • 💾 Persistent tokens - no re-login needed
  • 🔒 Secure token storage via libsecret
  • 👥 Multi-account support
